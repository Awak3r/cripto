## Задания (вариант на 4)

1. **Два симметричных алгоритма** (пара №24: MAGENTA + RC6), реализующих общий интерфейс симметричного алгоритма шифрования. Сторонние крипто-реализации запрещены.
2. **Консольное серверное приложение** (REST API / gRPC / и т.п., асинхронное), API поддерживает протоколы:
   - Регистрация по логин+пароль (пароль в открытом виде хранить нельзя — хеширование; логины уникальны)
   - Авторизация по логин+пароль → токен авторизации
   - Список файлов пользователя по токену: абсолютный путь уровня директории данных, размер в байтах
   - Добавление файла по токену (шифрование на стороне клиента выбранным алгоритмом из п.1 заданным ключом)
   - Получение файла по токену (дешифрование на стороне клиента)
   - Удаление файла по токену
   - Формат сериализации — на своё усмотрение; хранение файлов на сервере — в файловой системе
3. **Клиентское приложение** (консольное или оконное): регистрация, авторизация, добавление файла, получение файла. Интуитивный UI, аварийные ситуации недопустимы.
4. **Пояснительная записка** (распечатанная — обязательна для защиты) — см. ниже.
