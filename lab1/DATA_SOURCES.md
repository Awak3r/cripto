# Источники демонстрационных данных

Файлы в `data/` используются только как входные данные демо шифрования. Указанные ниже лицензии и права относятся к соответствующим сторонним файлам, а не ко всему репозиторию.

- **`data/image.bmp`** — официальное изображение Talia из Cyberpunk: Edgerunners 2, [страница издателя](https://www.cyberpunk.net/en/edgerunners2), [исходный PNG](https://www.cyberpunk.net/build/images/edgerunners2/characters/talia-f6ecd1a0.png). Преобразовано в RGB BMP, 250×410, 24 бита. Это не материал под Creative Commons; права принадлежат издателю. Включение в учебное демо не предоставляет разрешения на дальнейшее использование.
- **`data/music.wav`** — AlexZavesa, «Phonk Trap (Main Version)», оригинал Jamendo №439846; [копия в Internet Archive](https://archive.org/details/jamendo-439846). [Файл лицензии источника](https://archive.org/download/jamendo-439846/License.txt) указывает [CC BY-NC-ND 3.0](https://creativecommons.org/licenses/by-nc-nd/3.0/). Полный MP3 преобразован в WAV PCM: 16 бит, 44 100 Гц, стерео, ≈63,45 с, без творческих изменений. При дальнейшем использовании необходимо соблюдать условия лицензии, включая указание авторства, некоммерческий характер и запрет распространения переработок.
- **`data/video.avi`** — Sefra Correa, «Pet Cat», [страница источника](https://archive.org/details/PetCat), [исходный MP4](https://archive.org/download/PetCat/DSC_0680.mp4), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Полный ролик преобразован в AVI/MJPEG, 640×360, ≈8,74 с, без звука.
- **`data/allocator_red_black_tree_tests.cpp`** — файл из [DesCaldnd/FIIT_SP, коммит `6dd9f8db53292dba0261f65c087b8fcf0af0aeb5`](https://github.com/DesCaldnd/FIIT_SP/commit/6dd9f8db53292dba0261f65c087b8fcf0af0aeb5), [исходный файл](https://raw.githubusercontent.com/DesCaldnd/FIIT_SP/6dd9f8db53292dba0261f65c087b8fcf0af0aeb5/allocator/allocator_red_black_tree/tests/allocator_red_black_tree_tests.cpp). Сохранён без изменений; Git blob SHA-1: `2568d305801b44ff0cebb3b74be8577f2b9c9ca5`.
