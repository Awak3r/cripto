## Примечания на будущее
- `Decrypt` в DES: swap половин делается **до** вызова `feistel.Network.Decrypt` (IP даёт (R16,L16), сеть ждёт (L16,R16)) — не менять порядок.
- Таблицы DES сверены с FIPS 46-3 построчно (была ошибка в PC-1 строка 8 — исправлена).
- DEAL использует F от левой половины: до и после общей сети меняет половины местами. Фиксированный ключ расписания — `0123456789ABCDEF`, маски — `8000000000000000`, `4000000000000000`, `1000000000000000`, `0100000000000000`.
- `NewContext` принимает `func() interfaces.BlockCipher`: фабрика должна возвращать новый независимый экземпляр для каждого контекста. Nil-фабрика/nil-шифр и неверный ключ вызывают panic в конструкторе. `SetKey` не вызывается параллельно с шифрованием. Настроенный шифр допускает параллельные операции; контекст владеет копией IV. Вход и `dst` нельзя менять до получения результата из канала.
- Сеть Фейстеля копирует ключ перед расширением, глубоко копирует расписание и передаёт копии блока/ключа раундовой функции: in-place Transform допустим. Раундовая функция должна допускать параллельные вызовы и не перезаписывать чужие результаты. Таблицы DES не экспортируются.
- ECB, CTR/RandomDelta и расшифрование CBC/CFB распараллелены ограниченным числом воркеров. RandomDelta принимает положительный нечётный `int` (по умолчанию 1); счётчик — big-endian, сложение по модулю `2^(8*BlockSize)`. CTR/RandomDelta контролируют исчерпание периода внутри операции, включая набивку. Повтор IV между операциями этим не предотвращается. Формула RandomDelta — выбранный вариант CTR с дельтой; в ТЗ формулы нет, соответствие трактовке преподавателя не подтверждено.
- Файловый API (`internal/models/file.go`) обрабатывает порции по 64 КиБ с состоянием режима между порциями. Временный файл создаётся в каталоге назначения с правами 0600, затем Sync/Close/Rename; сохраняются биты доступа существующего обычного файла. Одинаковые пути допустимы. Ошибки очистки возвращаются. На Unix замена атомарна; вне Unix такой гарантии нет. Назначение-симлинк заменяется, его цель не перезаписывается. Сравнение файлов в демо тоже потоковое.
- `data/video.avi` — синтетическое видео ffmpeg testsrc (несжатое BGR24, 32×24, четыре кадра, 1 секунда). ffmpeg не нужен для работы программы.
- Zeros теряет исходные завершающие нули; для произвольных файлов использовать PKCS7. ISO10126 использует `math/rand` только для заполнения набивки; импортов `crypto/*` нет.
- Это учебный код без аутентификации, не средство защиты реальных данных. Исправления расписания DEAL и переноса CTR/RandomDelta меняют шифротекст относительно старой реализации.
- `data/enc/` — мусор от прогонов демо, можно чистить.
- Проверять форматирование, `go build ./...`, `go vet ./...` и демо с `-race` после изменений. Успешный `go test ./...` с `[no test files]` не означает прохождения алгоритмических тестов.
