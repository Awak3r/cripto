## Примечания на будущее
- `Decrypt` в DES: swap половин делается **до** вызова `feistel.Network.Decrypt` (IP даёт (R16,L16), сеть ждёт (L16,R16)) — не менять порядок.
- Таблицы DES сверены с FIPS 46-3 построчно (была ошибка в PC-1 строка 8 — исправлена).
- DEAL использует F от левой половины: до и после общей сети меняет половины местами. Фиксированный ключ расписания — `0123456789ABCDEF`, маски — `8000000000000000`, `4000000000000000`, `1000000000000000`, `0100000000000000`.
- `NewContext` принимает `func() interfaces.BlockCipher`: фабрика должна возвращать новый независимый экземпляр для каждого контекста. Nil-фабрика/nil-шифр и неверный ключ вызывают panic в конструкторе. `SetKey` не вызывается параллельно с шифрованием. Настроенный шифр допускает параллельные операции; контекст владеет копией IV. Вход и `dst` нельзя менять до получения результата из канала.
- Сеть Фейстеля копирует ключ перед расширением, глубоко копирует расписание и передаёт изолированные копии блока/ключа раундовой функции: in-place Transform допустим. Буферы аргументов принадлежат одной операции и переиспользуются между раундами после потребления результата F; сохранять аргументы после возврата нельзя. Раундовая функция должна допускать параллельные вызовы и не возвращать общий изменяемый буфер. Capacity аргументов ограничена их длиной, включая раундовые ключи разной длины.
- DES строит 42 КиБ lookup-таблиц IP/FP/E и совмещённых S+P один раз через собственную `Permute`; расписание ключей тоже использует `Permute`. Таблицы не экспортируются и после init только читаются. Шифротекст от этой оптимизации не меняется; constant-time гарантий нет.
- ECB, CTR/RandomDelta и расшифрование CBC/CFB распараллелены ограниченным числом воркеров. RandomDelta принимает положительный нечётный `int` (по умолчанию 1); счётчик — big-endian, сложение по модулю `2^(8*BlockSize)`. CTR/RandomDelta контролируют исчерпание периода внутри операции, включая набивку. Повтор IV между операциями этим не предотвращается. Формула RandomDelta соответствует предоставленному пользователем конспекту: `C_i = P_i XOR E_K(IV + (i-1)*delta)` при нумерации с 1. Дельта задаётся параметром, её случайная генерация не требуется. Ограничение на нечётность — дополнительная защита полного периода; в конспекте этого ограничения нет.
- Файловый API (`internal/models/file.go`) обрабатывает порции по 4 КиБ с состоянием режима между порциями. Временный файл создаётся в каталоге назначения с правами 0600, затем Sync/Close/Rename; сохраняются биты доступа существующего обычного файла. Одинаковые пути допустимы. Ошибки очистки возвращаются. На Unix замена атомарна; вне Unix такой гарантии нет. Назначение-симлинк заменяется, его цель не перезаписывается. Сравнение файлов в демо тоже потоковое.
- `data/video.avi` — Pet Cat автора Sefra Correa (CC0), настоящий ролик с котиком: AVI/MJPEG, 640×360, около 8,74 секунды, без звука. Источники медиа и лицензии — `lab1/DATA_SOURCES.md`. ffmpeg не нужен для работы программы.
- Zeros теряет исходные завершающие нули; для произвольных файлов использовать PKCS7. ISO10126 использует `math/rand` только для заполнения набивки; импортов `crypto/*` нет.
- Это учебный код без аутентификации, не средство защиты реальных данных. Исправления расписания DEAL и переноса CTR/RandomDelta меняют шифротекст относительно старой реализации.
- Демо не создаёт `data/enc/`: использует одну пару файлов в системном временном каталоге и удаляет каталог при завершении. Старый `data/enc/` — мусор прежних прогонов, можно чистить. При принудительном завершении процесса временный каталог может остаться.
- Файлы и режимы в демо перебираются последовательно. Требуемые асинхронность и параллелизм сохранены в API контекста и обработке независимых блоков; отдельный файловый worker pool не нужен.
- Проверять форматирование, `go build ./...`, `go vet ./...` и операции с `-race` после изменений. Успешный `go test ./...` с `[no test files]` не означает прохождения алгоритмических тестов.
- После оптимизации полный обычный запуск на текущих пяти файлах (~20,6 МиБ) прошёл за 60,4 с: 126 OK, exit 0, без оставшихся demo-каталогов (Ryzen 7 8845H, WSL2 linux/amd64, Go 1.26.5, 16 CPU). Это не результат полного прогона с `-race`; на других машинах время отличается.
