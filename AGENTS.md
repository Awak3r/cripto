# Лабораторная №1

ТЗ: `theotry/2526 МАИ ОК 1.pdf`, текст: `theotry/tz.txt`. Модуль Go: `lab1`.

- Собственные DES и DEAL на универсальной сети Фейстеля, собственные перестановки и адаптер DES.
- Семь режимов, четыре набивки, асинхронный API для байтов и файлов, параллельная обработка независимых блоков.
- Без готовых криптоалгоритмов, сторонних зависимостей, lookup-таблиц, кешей, лишних абстракций и комментариев в коде.
- Не добавлять тестовые файлы. Демо: `cd lab1 && go run ./cmd`. Сборка: `go build ./...`.
- DES использует swap после сети при шифровании и до сети при дешифровании. DEAL использует swap до и после сети.
- Ключ задаётся до параллельных операций. Вход и dst не менять до получения результата.
- Zeros не сохраняет исходные конечные нули. Для файлов в демо используется PKCS7.
- Файлы читаются целиком; учебный код не предназначен для защиты реальных данных.
